# تشغيل التتبع الحقيقي

## 1. ضع المفتاح في الاستضافة

أضف متغيرًا سريًا باسم:

```env
DATALASTIC_API_KEY=ضع_المفتاح_هنا
```

لا تضع المفتاح داخل ملف HTML ولا ترسله في المحادثة.

## 2. هيكل الملفات

- `forte-logistics-bilingual-mvp.html` — واجهة الموقع
- `api/vessel.js` — Backend آمن متوافق مع Vercel Functions

## 3. تشغيل محلي

شغّل المشروع من خلال خادم، وليس بفتح HTML مباشرة من `file://`، لأن المتصفح لن يجد المسار `/api/vessel`.

## 4. البحث الحي

المسار يستخدم Datalastic `vessel_pro` ويدعم:

- IMO من 7 أرقام
- MMSI من 9 أرقام
- UUID

الاسم النصي للسفينة يحتاج endpoint بحث منفصل من خطة Datalastic، لذلك استخدم IMO أو MMSI للنتيجة الأكثر موثوقية.
